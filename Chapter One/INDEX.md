# Chapter 1: How JavaScript Runs

Examples demonstrating the JavaScript runtime, event loop, and concurrency model.

## Examples

| File | Description |
|------|-------------|
| [ch01_hello.js](ch01_hello.js) | The "Hello" puzzle showing how different scheduling mechanisms (nextTick, setTimeout, setImmediate, Promises) are prioritized. |
| [ch01_deno_hello.js](ch01_deno_hello.js) | The same puzzle adapted for Deno runtime to show cross-runtime differences. |
| [ch01_puzzle.js](ch01_puzzle.js) | Advanced concurrency puzzle with worker threads, child processes, SharedArrayBuffer, and Atomics. |
